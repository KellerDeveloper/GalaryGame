# План: ребрендинг GalaryGame → Trash Panda 🐼

## Концепция
Trash Panda — панда-маскот, которая «жрёт мусор» с телефона. Существующий свайп-триаж/
удаление оформляем как «панда съела мусор» (анимация + звук/haptic). Не новая механика —
визуальная надстройка над готовым удалением.

Полный ребрендинг: название везде, снос DOS/Garden-концепции, тема/ранги под панду.
Делаем **поэтапно**, каждый этап заканчивается сборкой + сдачей на проверку.

---

## Этап 1 — Переименование проекта (identity)
Проект собирается через XcodeGen → переименование безопасное (правим `project.yml`, регенерим).

- `project.yml`: `name`, target `GalaryGame`→`TrashPanda`, `GalaryGameTests`→`TrashPandaTests`,
  `sources.path`, `INFOPLIST_FILE`, `PRODUCT_BUNDLE_IDENTIFIER`
  `com.kellerdeveloper.galarygame` → `com.kellerdeveloper.trashpanda`
- `git mv` папок: `GalaryGame/` → `TrashPanda/`, `GalaryGameTests/` → `TrashPandaTests/`
  (git mv — сохраняет историю)
- `GalaryGameApp.swift` → `TrashPandaApp.swift`, `struct GalaryGameApp` → `struct TrashPandaApp`
- `Info.plist`: `CFBundleDisplayName` = `Trash Panda`, обновить usage-строки (текст про панду)
- `xcodegen generate` → `BuildProject`

**Проверка:** проект собирается, на домашнем экране — «Trash Panda», тесты компилируются.

## Этап 2 — Панда-маскот + «съела мусор»
- Заменить таб «Сад» (GardenView) на **PandaView** — экран с маскотом, показывает
  состояние панды (сытость/прогресс уборки).
- В `SwipeTriageView`: удаление оформляем как «панда съела мусор» — анимация + haptic
  (+ звук опционально).
- Тексты табов под бренд («Порядок» оставить, иконки/названия по ходу).

**Открытый вопрос (нужен ответ):** где берём графику панды?
  - a) placeholder на SF Symbols / простая векторная отрисовка (быстро, некрасиво)
  - b) ты дашь готовые PNG/ассеты панды
  - c) сгенерить ассеты отдельно
→ по умолчанию начну с (a) placeholder, чтобы механика работала, потом заменим арт.

**Проверка:** свайп по фото → панда «ест» его (анимация играет), таб панды открывается.
